LinkSieve

Support

LinkSieve is free, with no ads or purchases. Android 8.0 or later is required.

A code will not scan

Include the entire code and its clear border. Improve the lighting, avoid reflections, or move slightly farther away. Use the scanner's Light control if available. For a code on the same device, choose Import image. Some damaged, very small or unsupported codes cannot be decoded. LinkSieve supports common QR, Aztec, Data Matrix, PDF417, EAN, UPC, Code 39, Code 93, Code 128, ITF and Codabar formats through ZXing. It does not claim every barcode variant.

Camera access is unavailable

Choose Scan code to request permission. If Android no longer asks, open Android Settings, Apps, LinkSieve, Permissions and enable Camera. Import image and pasted text work without camera permission.

Understand a link

The Host field identifies the destination named by the URL. A warning is an explanation of URL structure, not a safety verdict. A site may redirect after you open it. LinkSieve performs no reputation lookup. Cleaning removes only recognized tracking keys; it cannot remove all tracking. Recognized signatures and access tokens disable cleanup.

Create and share

Open Create, choose Text, Link, Wi-Fi or Contact, enter the fields and select Generate QR. Export PNG writes a 1024 by 1024 image. Share image opens Android's share sheet. Always scan-test before printing. QR contents are limited to 1,800 UTF-8 bytes for readability. Wi-Fi QR images reveal the network password to anyone who can scan them.

Move your saved library

In Library or Settings, choose Export backup and save the archive somewhere you trust. On the other device, choose Restore backup and select the file. LinkSieve checks the file before asking to replace the current library. Preferences are not replaced. A failed validation leaves current codes unchanged. Archives have a 5 MB limit and at most 10,000 records; a code that would exceed backup capacity is not added. Keep backups private because they are not encrypted.

Delete your data

Delete a record in Library, or choose Delete all saved codes in Settings. To remove preferences, current fields and cached exports too, use Android's Clear storage or uninstall. Delete exported copies and clipboard contents separately. There is no account or server copy.
