FolioFold

Support and printing guide

FolioFold prepares PDFs for printing. It does not certify a printer's paper-feed behavior or guarantee borderless output.

Prepare your first booklet

  1. Import an unprotected PDF, or open the folding sample.
  2. Choose Booklet in Layout. Set paper dimensions, margins and the gap. Apply the layout.
  3. Use Preview to check each sheet front and back. Reading-page labels map back to source pages.
  4. Use Output to prepare all sides, only fronts or only backs. Save, share or print the prepared PDF.
  5. Use actual size or 100% scale where available. Disable printer booklet and N-up processing because FolioFold has already arranged the pages.

Manual duplex

Mark the top edge of a sheet. Prepare calibration A in Output and print it. Reinsert the paper according to your printer's feed path, then prepare and print calibration B. Turn the sheet like a book. If B is upside down, change Back rotation in Layout and test again. A two-sheet numbered test reveals whether the back stack should be reversed. Save the successful settings as a preset.

The included 20 mm ruler is exact on A4 landscape at 100% print scale. On other paper sizes it is a feeding-direction test. Actual printer scaling and unprintable margins may differ.

Signatures, zines and handouts

Signatures group reading pages at your chosen size, with the last group padded to a multiple of four. Eight-page zines use four columns and two rows on one side, with the top row rotated. Fold the sheet into quarters and halves, cut the center horizontal slit between the first and third column creases, then collapse it into a book. Optional dashed guides mark folds; the solid segment marks the cut. N-up arranges consecutive pages across rows or down columns.

What flattening means

Print outputs contain page images at nominal 300 dpi. They do not retain selectable text, links, editable forms or unlimited vector resolution. Your imported source remains unchanged and can be exported separately. Check the preview and a small print before a large run.

File limits and errors

PDF input supports up to 128 MiB and 1,000 pages. Edited reading order supports up to 1,200 pages. Paper sides can be 50 to 450 mm. Archives support 512 MiB of expanded data, up to 200 projects and 200 presets. Prepared outputs are limited to 1 GiB. Split a larger source into smaller PDFs using your preferred document tool.

For a protected or unsupported PDF, export an unprotected copy first. If storage runs out, free space and prepare the file again. If a provider denies access or removes a file, select it again. Keep FolioFold open during export; cancelling does not produce a completed file. An interrupted export can be restarted from the saved project.

Move or recover projects

Export a complete archive in Settings before uninstalling or moving devices. Restore validates its contents before replacing projects and presets. Malformed imports leave existing records intact. Archives contain original documents without encryption. Keep a separate safe copy. Android automatic backup is disabled.

Paper size in Android print

Choose the same paper dimensions and orientation as your FolioFold layout. FolioFold stops the print preview if the print service selects a different size. For unsupported custom paper, use Save PDF and print the file from software that supports your paper. Check printer margins and print a calibration sheet before a complete run.
