Gearwake support

Send questions to shayanm2002@gmail.com. Include your Android version, workshop, round and seed when reporting a gameplay issue. Never send passwords or payment card information.

Understand a production chain

Open Manual in the app. An arrow sends goods to the adjacent cell. Empty exits dispatch goods; structural columns block them. Machines receive only the inputs their recipes accept. Each beat produces first and transfers second, so newly received inputs are processed on the next beat.

Recover or move a run

Settings has Export complete backup and Restore backup. A backup includes the current run, placement undo and finished results. Restoring replaces those records after validation. Preferences stay on the device. Automatic cloud backup is disabled, so make a file before uninstalling or changing phones.

Fix a file error

Choose a writable destination with enough free space. Download a cloud-hosted backup fully before importing it. An unavailable, corrupt or unsupported archive is rejected without replacing saved records. A failed export may leave an incomplete file at the chosen destination; delete that file and try again.

Replay and daily challenges

A seed plus workshop selects the same offers under the same rules version. Restart resets the current run. The daily start follows UTC, which may change at a different local time than midnight. There is no online leaderboard or live synchronization.

Purchases and refunds

All gameplay is included in the upfront purchase. Use the Google account that purchased Gearwake to reinstall it. For order or refund help, see Google Play refund help. Eligibility and processing are handled by Google.

Delete your data

Use Delete local runs for saved runs and records. Clear app storage in Android Settings or uninstall to also erase preferences. Exported files and shared copies must be deleted separately.
